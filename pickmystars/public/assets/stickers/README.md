# Y2K 스티커

사용자가 제공한 `_ (13).jpeg`, `_ (14).jpeg`, `random y2k png icons_.jpeg`를 참고해 이미지 생성 도구로 배경을 제거하고 14종을 재구성한 투명 PNG 시트입니다. 원본의 모든 요소를 포함하지는 않습니다.

`src/photo/stickers.ts`의 픽셀 영역으로 각 스티커를 표시합니다. 브라우저와 이메일용 Canvas 출력 모두 같은 영역·좌표·회전을 사용합니다.

- 안경 3종, 도트 별, 도트 하트, 음표
- 젤리 곰, 날개, 은색 별, 민트 반짝임, 러브, 말풍선

`y2k-extras.png`에는 첫 번째 참고 이미지의 헬로키티 안경, 두 번째 이미지의 검정 도트 별과 리본을 재구성했습니다. 별 안경은 목록에서 제외했습니다.
