# P!ck My St☆r

2026 MSG 관악구 청아즐 페스티벌 전시 부스를 위한 아이돌 이상형 월드컵 웹앱입니다.
한 대의 전시용 컴퓨터에서 로그인 없이 월드컵을 진행하고, 우승한 아이돌과 네컷 사진을 남기는 흐름으로 구성했습니다.

## 현재 구현

- 남자·여자 아이돌 카테고리 선택
- 16강·32강·64강 랜덤 대진, 승자 진출, 라운드별 진행 게이지
- 최종 우승자 결과와 포토부스 연결
- 웹캠 네컷 촬영, 3·5·10초 타이머, 프레임 색 변경, 다시 찍기, 이메일 전송 요청
- Firebase Realtime Database 연결 및 최종 우승 횟수 누적
- Firebase 설정이 없는 로컬 환경에서도 게임·촬영 화면 실행

남자 아이돌은 64명 명단과 대표 사진이 연결되어 있습니다. 여자 아이돌도 64명 대표 사진을 연결했습니다. 기존 사용자 제공 사진 2장과 공식 프로필·공식 영상 썸네일·공식 사진 기사 재게시 자료를 사용했습니다. 출처는 `pickmystars/docs/GIRL_PHOTO_SOURCES.md`에 기록했습니다.
사진 이메일 전송 UI·API가 구현되어 있으며 실제 발송에는 메일 서비스 설정이 필요합니다. 순위 화면은 아직 구현하지 않았습니다. 순위 조회 함수는 준비되어 있습니다.

## 시작하기

Node.js 22.12 이상과 npm이 필요합니다. 저장소를 클론한 뒤 **`pickmystars` 폴더에서** 실행합니다.

```sh
cd pickmystars
npm install
npm run dev
```

터미널에 표시되는 주소를 엽니다. 기본 주소는 `http://localhost:5173`이며, 포트가 사용 중이면 달라질 수 있습니다.
실행 중에는 터미널을 열어 두고, 종료할 때는 `Ctrl + C`를 누릅니다. React 프로젝트이므로 HTML 파일을 직접 열거나 Live Server로 실행하지 않습니다.

빌드, 검사, Firebase 설정과 폴더 구조는 [앱 README](pickmystars/README.md)를 참고하세요.
